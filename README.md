# ai-short-drama · AI 短剧创作库

把「竖屏短剧分镜 + AI 生成提示词」的全流程产出，按剧集归档。

每一集都包含四层可交付物：**可拍的分镜表**、**可复制进生成模型的提示词**、**机器可读的数据**、**可复用的方法规范**。

## 为什么会有这个库

1. **短剧的钱不在产能，在「被看见」**。所以每一集都按 15 秒一个单元来切，每个单元必须有功能、情绪曲线和一个钩子——这是留存率的最小抓手。
2. **AI 生成崩的不是分镜，是「像不像同一部片」**。所以提示词不写给灵感，写给一致性：固定四行结构 + 角色锚 + 负面词库。
3. **好产出会散**。剧本、分镜、提示词、参数散在聊天记录里就废了。所以统一入库，按集归档，一集一个目录。

## 方法论速览

### 一、15 秒单元法

一个 15 秒单元 = 一次生成交付 = 一次剪辑对齐。单元内部再切 3–5 个镜头（每镜 3–5 秒）。

每个单元必须回答三个问题，答不出就不该存在：

- 这一段**必须完成**什么（信息 / 关系 / 情绪）
- 情绪怎么走（起 → 转 → 落）
- 观众凭什么不划走（钩子）

12 个单元拼成 180 秒，就是一集。单元为整 15 秒，可直接作为验收单位。

### 二、四行提示词

```text
主体动作 + 镜头（景别 / 焦段 / 机位 / 运动）+ 光色（色温 / 光源 / 影调）+ 风格（质感 / 参考 / 画质）
```

三条硬规则：

1. 一条提示词只描述**一个连续动作**，不写「先…再…最后…」。
2. 不写抽象情绪（「悲伤」），改写可见的生理细节（睫毛乱两拍、指节泛白）。
3. 镜头里出现的每样东西都要能被看到，不写心理活动。

### 三、三道一致性防线

- **角色锚**：每个角色一组固定描述串，逐镜追加，缺一个就重生成。
- **负面词库**：中英双语，统一追加，不逐条改写。
- **参数纪律**：单段 5–8 秒、首尾帧法衔接、运动幅度 2–4、只允许少量升格。

完整版见 [方法与规范](docs/00-方法/竖屏短剧分镜与提示词规范.md)。

## 快速开始

```bash
# 1. 改数据（镜头、台词、提示词都在这里）
$EDITOR scripts/v2_data.py

# 2. 重新导出提示词与结构化数据
python scripts/export_prompts.py
# → data/EP01.json、prompts/EP01-prompts.md、prompts/EP01-prompts.txt
```

生成流程（推荐顺序）：

1. 每单元先出「定妆参考帧」：同角色锚、同种子、同光色。
2. 批量出 4 个镜头，只换「主体动作」与「镜头」两行。
3. 4 镜对齐 15 秒 → 配音与音效对位 → 字幕进安全区。
4. 统一调色（夜段青黑 / 晨段青金），导出。
5. 只重生成出错的那 5–8 秒，不整单元重做。

## 协作约定

新增一集时：

1. 建 `docs/EP0X-剧集名/`、`prompts/EP0X-prompts.md`、`data/EP0X.json`。
2. 数据源统一放 `scripts/`，导出脚本复用 `export_prompts.py` 的结构。
3. 文件名规范：`EP0X_分镜脚本_Vn_说明.docx`。
4. 更新根 `CHANGELOG.md`，写清改了设定、改了结构、还是改了提示词。
5. 提交信息：`feat(EP02): 新增分集卡与 12 个单元` / `fix(EP01): 修正 U09 报价台词`。

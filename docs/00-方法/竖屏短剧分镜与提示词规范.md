# 竖屏短剧分镜与提示词规范

适用于 9:16 竖屏、单集 2–4 分钟、AI 生成与实拍混合的短剧。本规范是 `prompts/`、`data/` 与各集分镜脚本的写作依据。

---

## 1. 15 秒单元法

### 1.1 为什么是 15 秒

- **生成侧**：主流模型单段 5–8 秒，15 秒 = 2–3 段，正好一批出完，便于批量返工。
- **剪辑侧**：15 秒是「对齐」和「重做」的最小代价单位。
- **验收侧**：单元时长固定，完播率、流失点可以逐单元回填数据。

### 1.2 单元卡写什么

每个单元只写五行，写不出就是这段戏不该存在：

| 字段 | 要求 |
| --- | --- |
| 功能 | 这一段**必须完成**的信息 / 关系 / 情绪，只写一件事 |
| 情绪曲线 | 起 → 转 → 落，三个词，不许是直线 |
| 观众钩子 | 看完这段，观众心里冒出的那个问题 |
| 声音 | BGM 情绪 + 关键音效（声音先于画面建立节奏） |
| 转场 | 用「物」转：烛火、帘子、钱袋、铃声；不用叠化 |

### 1.3 单元内镜头分配

12 个单元 × 15 秒 = 180 秒，每单元 2–5 镜，全片特写占比不低于 40%（竖屏逻辑：看得清情绪比看得见场面重要）。

## 2. 竖屏六条铁律

1. 面部占屏高 1/3–1/2，眼睛压在上三分线。
2. 顶部 1/6、底部 1/5 为安全区（平台字幕、贴纸、进度条），重要信息不放进去。
3. 少用横摇，多用纵向运镜（升降 / 前后推拉 / 纵深跟拍）；竖屏的「宽」是假的，「深」才是真的。
4. 双人对话一律「越肩 + 正反打」；必须同框时用前后错位站法，绝不横排并列。
5. 每个情节点至少留 1 帧「可截图画面」（封面 / 切片 / 投流素材）。
6. 转场优先用「物」，不用叠化，硬切更利落。

## 3. 四行提示词

### 3.1 公式

```text
主体动作 + 镜头（景别 / 焦段 / 机位 / 运动）+ 光色（色温 / 光源 / 影调）+ 风格（质感 / 参考 / 画质）
```

四行写完，不写第五行。角色锚与负面词统一追加，不逐条重写——这是 48 个镜头「像同一部片」的唯一办法。

### 3.2 三条硬规则

1. 一条提示词只描述**一个连续动作**，不写「先……再……最后……」，需要多动作就拆镜。
2. 不写抽象情绪词（「悲伤」「愤怒」），改写**可见的生理细节**：睫毛乱两拍、指节泛白、喉结滚动、耳根泛红。
3. 镜头里出现的每样东西都要能被看到，不写心理活动，不写画外信息。

### 3.3 反面例子

| 错误写法 | 问题 | 改法 |
| --- | --- | --- |
| 「男主很悲伤地看着她」 | 抽象情绪，模型只会给通用苦脸 | 「他垂眼，下眼睑先松，视线落在她鞋尖上，喉结动了一下」 |
| 「镜头缓缓推进，然后他转身离开」 | 两个动作，模型会糊成一个 | 拆两镜：推近 / 转身离开 |
| 「古装美女」 | 无锚点，每次生成都不一样 | 「20 岁苗疆少女，浅蓝对襟长裙，左耳银铃，眉心淡青花钿」 |

## 4. 角色锚

复制到每条提示词末尾，缺一个就重生成该条。

```text
男主：25岁东方古装男子，墨蓝色暗纹交领锦袍，高束墨发，肤色偏白带病气，左手食指墨玉戒，眼尾微挑，唇色偏淡，清瘦挺拔，慵懒矜贵。
女主：20岁苗疆少女，浅蓝色对襟长裙，左耳银质小铃，眉心淡青花钿，腰间旧皮药囊，指腹有药渍与细小伤口，圆眼俏鼻，肌肤白皙，灵动明艳。
护卫：28岁玄色劲装护卫，护腕束袖，高束发，眉骨一道旧疤，肩宽背直，神情警觉，腰悬木牌。
灵兔：雄性灵兔，咖白相间短毛，左耳缺一小口，颈间系旧铜铃，眼如红豆，体型小巧精悍，四肢有力，毛发根根分明。
```

**场景锚**

- 角楼内：木构高台、苇帘、青砖地、铜烛台、矮榻与锦垫、窗外可见山脊与月，室内只有烛火一个暖光源。
- 长街市集：依山而建的部落长街，两侧木质摊位与竹匾，干货、山货、成捆草药，蒸笼白汽，青灰石板路，晨光侧逆。
- 山脊月夜：墨色山脊线、将满圆月、薄云、山谷零星灯火、青黑基调。

## 5. 通用负面词

**中文**：多余肢体、六指、手指畸变、双眼不对称、面部崩坏、塑料皮肤、过度磨皮、假人感、卡通渲染、日漫风、3D 建模感、现代服饰、现代建筑、电线、文字、字幕、水印、logo、表情包、夸张表情、动物拟人化穿衣服、雌性化兔子、过曝、死黑、运动模糊过度、镜头剧烈抖动、慢动作滥用、绿幕边。

**英文**：`extra limbs, deformed hands, six fingers, asymmetric eyes, face distortion, plastic skin, over-smoothed, cartoon, anime, 3D render, modern clothing, text, watermark, logo, oversaturated, motion blur, shaky camera, green screen edge.`

## 6. 参数与拼装

| 项 | 建议 |
| --- | --- |
| 单段时长 | 5s 为主，复杂动作 8s；一个 15 秒单元拆 2–3 段 |
| 首尾帧法 | 取上一镜末帧作下一镜首帧图，保证姿态、光线、构图连续；跨单元不需要 |
| 运动幅度 | 0–10 档，文戏 2–4，追逐可到 6；超过 7 容易面部崩坏 |
| 画幅帧率 | 9:16，1080×1920；常规 24fps，升格段 60/90/120fps 单独生成后放慢 |
| 镜头词映射 | 缓推=dolly in / 缓拉=dolly out / 摇=pan / 移=truck / 跟=follow / 升降=crane / 甩=whip pan / 微距=macro / 变焦=zoom / 焦点转移=rack focus |
| 拼装顺序 | 生成 4 镜 → 对齐 15s → 配音与音效对位 → 字幕进安全区 → 统一调色 → 导出 |
| 返工边界 | 只重生成出错的那 5–8 秒；人物锚错了改锚，光色错了改光色行，别动其他行 |

## 7. 常见崩坏与改法

| 症状 | 根因 | 改法 |
| --- | --- | --- |
| 几个人一张脸 | 轮廓、发型、饰品差异不足；提示词只写「古装男子」 | 加大剪影差异（身高 / 肩宽 / 发冠 / 披风），锚点必入提示词，同角色固定种子 |
| 手部六指、钱袋穿模 | 手部交互是模型最弱项 | 手部特写改实拍或后期合成，AI 只负责环境与光 |
| 宠物像玩偶 | 只写「小兔子」，没写性别、体态、发力 | 写 male rabbit / buck；写四肢蹬地发力；耳朵与铃是唯一表情 |
| 毒纹像纹身 | 用了「图腾 / 发光 / 阵法」 | 改「皮下冰纹、青黑、低对比」；只在特写出现，不进全景 |
| 灵光像魔法 | 粒子、辉光、能量球用词过多 | 只留「鼻尖向上一缕」，配极弱高频音，单镜不超过 1 秒 |
| 慢动作滥用 | 全片统一升格 | 只允许 4 处升格，其余 24fps |
| 口型对不上 | 先出画面后配音 | 静帧 → 定配音 → 口型驱动，台词不临场改 |
| 色调不统一 | 逐镜单独调色 | 统一两套 LUT：夜段、晨段各一套 |

## 8. 声音设计三条规则

1. **病发不用音效，用呼吸**：呼吸频率不变，只在两次呼吸之间多一个极短的停顿，剪辑点卡在抬眼瞬间。观众说不出哪里不对，但会不舒服。
2. **灵力只给极弱高频**（8–12kHz，-30dB 以下），全片出现 3 次；第四次就俗了。
3. **符号音必须成对**：两枚铃要同帧同拍，起振点对齐 ±10ms 才像「共振」；叠音后留 1 秒静默。

## 9. 留存卡点逻辑

按单元排卡点，而不是按剧情排：

| 时间位 | 该放什么 | 判断标准 |
| --- | --- | --- |
| 0–15s | 冷开场 + 立设定 | 前 5 秒流失率 < 25% |
| 15–30s | 权力关系 / 悬念钩 | 首波评论出现 |
| 30–45s | 倒计时或目标 | 观众开始替角色算 |
| 45–60s | 场景切换，防疲劳 | 全片最大流失点，靠光色与音乐换挡 |
| 中段 | 冲突 / 可爱 / 心动 | 每 15 秒一个可切片瞬间 |
| 末 15s | 信息差钩子 | 追更率 / 下集完播率 |

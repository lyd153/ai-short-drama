# 挽回线 · 12 集激情衔接版大纲

> 改版原因：EP01 已改成「剑架脖子 + 三日之约 + 查她的核」的高压开局。若后面回到「请喝茶、逛集市」的日常节奏，情绪会泄掉。
> 本版把 12 集改成**一条不断线的债**：每集都有一笔要还的账、一次升级的亲密、一个更狠的钩子；每集开场 3 秒**直接接上集最后一帧**，不做时间跳跃。
> 时长：EP01 = 120 秒 / 8 段；EP02–EP12 = 60 秒 / 4 段；每段 15 秒。

---

## 一、总情绪曲线（不许回落）

```text
EP01 剑在脖子上（险 10）
EP02 三日到期·草没了（险 9）
EP03 十五·他倒在她面前（险 9，第一次救）
EP04 她救阿婆·他倒下（虐 8）
EP05 她守夜·换药（亲 7）
EP06 男二登场·「他会取你的核」（疑 8）
EP07 雨夜·她主动吻（亲 10）
EP08 密信·他烧信（险 9）
EP09 月下·表白与拒绝（甜虐 9）
EP10 摊牌·她走（虐 10）
EP11 她被掳·他交出灵息（惨 10）
EP12 救回·原谅·吻（甜 10）
```

**规则**：每集必须有一件「说出去会死人」的事，且不能让上一集的高压低于 8 分。

## 二、12 集逐集设计

| 集 | 开场 3 秒（接上集） | 本集高压事件 | 本集亲密/甜点 | 信息（靠对话） | 结尾钩子 |
| --- | --- | --- | --- | --- | --- |
| **EP01** | 剑横颈侧 | 她来讨草、他反将（捏剑身带她前倾） | 剑贴颈、托手接茶 | 草能救命、他是主上、他病了 | 「三天还她」＋「查她的核」＋「骗她喜欢我」 |
| **EP02** | 三日到期，她推门进来 | **草只剩半株**（兔子啃了），她当场翻脸 | 他把手腕伸给她：「要还就还这条命」 | 草是给阿婆救命的药（她第一次说出用途） | 她说「三天前你不知道，现在你知道了」＋他吩咐「把库里剩下的都给她」 |
| **EP03** | 她抱着空药篓离开的背影 | **十五毒发**，他倒在她必经的路上 | 她跪在雨里按住他腕脉，他抓住她手腕说「别走」 | 十五发作、他只信她 | 他昏过去前一句：「草……先送去。」 |
| **EP04** | 他发着烧躺在药庐门口 | 她把他拖进去，用掉最后半株草救人 | 她喂药、擦汗、骂他；他装睡听 | 阿婆的命压着、她自己也没药了 | 他睁眼：「你把草用在阿婆身上，那你呢。」 |
| **EP05** | 他半夜醒来，看见她趴在床边 | 她发烧（淋雨救人染的） | 他第一次抱她上床、替她盖被、替她换药 | 她说「你别死，我阿婆还没好」 | 她在他袖口看见毒纹，愣住：「你比我阿婆还重。」 |
| **EP06** | 她盯着他手腕的毒纹 | **萧漓登场**（灵泉百合化形，替她诊脉） | 萧漓替她披衣，他一把扯下来 | 他体内有核、能救他 | 萧漓临走：「他若知道，会取。」 |
| **EP07** | 他在门外听见这句 | 山雨困在山洞；她试探「若我的命换你的命」 | **她主动吻他**（第一次） | 她把选择权交给他 | 吻完他低声「别拿命开玩笑」，她笑「我没开玩笑」 |
| **EP08** | 他回房盯着那封信 | **老主母密信：取核可续命，取核者死** | 他烧信时她撞见火光 | 取核的代价、母亲知道一切 | 她问「你在烧什么」，他说「没什么」 |
| **EP09** | 她站在他背后没走 | 他带她看月，想说实话，说不出口 | 「我不信命，我信你」＋她吻他眼角泪痣 | 他怕她知道真相 | 她笑：「你今天话很少。」 |
| **EP10** | 萧漓把一封信拍在桌上 | **摊牌**：他第一天就知道她是玄女 | 他伸手想拉她，她退开「别碰我」 | 全盘真相 | 雨里他砸了药碗：「我不要命了。」 |
| **EP11** | 她被押走的那一刻 | **她被掳**（敌人要核） | 他抱着她喊「对不起」 | 取核＝失魂 | 他交出灵息，霜从脚下漫开 |
| **EP12** | 他抱着她瘫在雪地上 | 她醒来，记得一切 | **原谅＋吻＋一起看月** | 他放弃核、放弃命 | 尾字幕「第一季·完」：「我欠你的，用一辈子还」 |

## 三、男二萧漓（绿茶·挑拨线）

- 每次出场都「只说她最需要听的那半句」，且句句是真话。
- EP06：「他体内有核，能救他。你要不要救？」→ 把「取」说成「救」。
- EP07：「他若知道，会取。」→ 事实，也是最狠的一刀。
- EP10：把密信拍桌上，让她自己看。
- EP12：退场句「我输在他比我敢欠」。

## 四、亲密戏分布（每两集一次升级）

| 集 | 亲密级别 |
| --- | --- |
| EP01 | 剑贴颈、托手（0 级：身体被迫接近） |
| EP03 | 他抓她手腕、她跪在他身边（1 级：求助） |
| EP05 | 他抱她上床、盖被、换药（2 级：照顾） |
| EP07 | **她主动吻他**（3 级：吻） |
| EP09 | 她吻他眼角泪痣（3 级加强） |
| EP11 | 他抱她、埋在她颈侧（4 级：依偎） |
| EP12 | 吻 + 额头相抵 + 一起看月（5 级：HE） |

## 五、对话硬指标（每集）

1. 每集 4 段、16 镜，**至少 14 镜有台词**。
2. 每集至少一句「扎心真话」（多由男二或她自己说出）。
3. 每集至少一句她的「直球」＋他的一句「回避」。
4. 每集结尾最后一句必须是独白或半句话（不给完整答案）。

## 六、每段功能（60 秒集）

| 段 | 功能 |
| --- | --- |
| D1 | 接上集最后一帧，3 秒内让观众「哦，还没结束」 |
| D2 | 本集高压事件爆发 |
| D3 | 亲密升级（身体接触） |
| D4 | 信息揭示 + 钩子 |

## 七、与上一版的差异

- 上一版：EP01 冷开场（集市抢草），EP02 才进茶馆，节奏是「爬坡」。
- 本版：EP01 已经剑在脖子上，**从第一秒就是最高压**，之后每集都在这条线上加码，没有一集回到「日常甜」。
- 唯一允许的「甜」是夹在高压里的**短刺**（一句台词、一次触碰），不单独做甜集。

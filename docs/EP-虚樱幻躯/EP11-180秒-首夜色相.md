# EP11 · 首夜 · 色相（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s｜**第二个死亡**
> 本集任务：与 EP10 形成对照——林软死于「想救」，周浪死于「想要」；**同一个晚上，两种贪**。
> **合规要求**：不做色情、不做裸露、不做鬼脸；诱惑靠光影、气味、声音，沉沦靠表情；死亡为「碎裂成片」，不流血。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，明亮日光，裸露，情色
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

# EP20 · 樱落 · 共生（240 秒 / 16 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜**240s（收尾加长集）**
> 本集任务：全剧收束——**他不留下，但带她走**；樱花第一次落地，幻境崩，诡域引渡觉醒，三人脱出，ICU 里她渡本源救他。
> **合规要求**：怨灵真身不做鬼脸、不做血腥；崩解靠"花瓣落地""空间剥离""金光"表现。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，杂乱背景
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

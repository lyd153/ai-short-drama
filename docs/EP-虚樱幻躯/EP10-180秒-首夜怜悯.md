# EP10 · 首夜 · 怜悯（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s｜**全剧第一个死亡高潮**
> 本集任务：让观众亲眼看见「**她不是被杀的，是自己留下来的**」——死亡拍成自愿，比拍成暴力更狠。
> **合规要求**：不做血腥、不做鬼脸、不做撕咬；消失方式统一为「化成樱粉色细屑」，从指尖开始。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，明亮日光，杂乱背景
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

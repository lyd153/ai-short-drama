# EP18 · 玉珏（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s
> 本集任务：苏泠破戒——**她藏了十四集的东西，终于被逼出来用掉最后一次**；也是全剧唯一一次「用道具解决问题」，代价即人。
> **合规要求**：反噬不做七窍流血，用「眼白布满细丝、唇色褪尽、额头冷汗、站不住」表现。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，杂乱背景
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

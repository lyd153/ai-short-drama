# EP16 · 次轮 · 乌托邦（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s｜**第三个死亡**
> 本集任务：陈缩死于「想休息」——**他不是被拖进去的，是坐下就不肯起来了**。死法定为「木化僵住」，与林软的樱粉、周浪的纸片三种不同。
> **合规要求**：不做血腥、不做鬼脸；木化是缓慢的、静默的，靠质感变化与声音（木裂）表现。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，杂乱背景
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

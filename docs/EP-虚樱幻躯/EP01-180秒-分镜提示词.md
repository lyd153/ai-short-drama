# EP01 · 樱惑骨魅 · 载入（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜总时长 180s
> 运镜基调：参照《觉醒伪神》——暗角、边缘轻微空间畸变、低饱和灰调、28mm、呼吸感晃动、慢节奏、无快切

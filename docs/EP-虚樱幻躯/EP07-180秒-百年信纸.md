# EP07 · 百年信纸（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s
> 本集任务：抛出全剧最重的宿命线索——**信纸上的字迹，和沈砚一模一样**；让他第一次失态，让苏泠第一次主动靠近他。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，狰狞鬼脸，夸张表情，卡通厚涂，明亮日光，杂乱背景，现代建筑
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

# EP12 · 三条铁律（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s｜**全剧第一个推理爽点**
> 本集任务：把前十一集所有碎片（花瓣、窗户、刻痕、老人、信纸、两场死）串成三条铁律——**观众跟着沈砚一起"想通"**。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，伤口，狰狞鬼脸，夸张表情，卡通厚涂，明亮日光，杂乱背景
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

# EP05 · 温柔是假的（180 秒 / 12 段）

> 规格：720P｜24fps｜Seedance 2.0 Fast｜180s
> 本集任务：残魂开始**按每个人的欲望投喂幻象**——老人给林软讲故事、少女幻象勾周浪；把「双话语意」拍到极致，最后一句把刀递给沈砚。
> **统一负面词（本集全段适用）**：快速镜头切换，剧烈抖动，高饱和色彩，爆炸光效，血腥，狰狞鬼脸，夸张表情，卡通厚涂，明亮日光，杂乱背景，现代建筑
> **统一画风底稿**：日式悬疑恐怖漫剧，暗角，边缘轻微空间畸变，低饱和灰调，28mm 电影镜头，轻微呼吸感晃动，慢节奏，无快切。

## 本集自检

| 项 | 结果 |
| --- | --- |
| 时长 | 12 × 15s = 180s ✅ |
| 双话语意 | 老人「讲个故事」= 留人；「把花种死的人」= 百年前背叛者 ✅ |
| 幻象规则 | 少女双脚不落地、手掌穿过（花瓣拼的）✅ |
| 人物推进 | 林软被动摇、周浪色心被吓退、陈缩只会躲、陆耀用"护人"证明自己 ✅ |
| 日语台词 | 3 句（優しいね／いつも見ている／彼もそう言った）带罗马音与字幕 ✅ |
| 钩子 | 「你也会把一个东西种死」＋绳头递给沈砚＋「他当年也是这么说的」✅ |

## 四、美术与拍摄硬约束

1. **身高 220cm 是布景参数**：门楣净高 ≥2.4m（他进门必须明显低头）、榻长 ≥2.6m、摊位台面 1.1–1.2m（他俯身看货要弯腰）、群演 170–175cm。
2. **44cm 身高差是机位参数**：他俯视、她仰头；他俯身时镜头随之前压；同框优先「他的脸 / 她的脸」分切，避免全身同框比例失真。
3. **两套 LUT**：夜段青黑（6500K 冷月 + 烛暖）、日段青金（4300–5600K 逆光）；全片只用这两套。
4. **竖屏安全区**：上 1/6、下 1/5 不放关键信息。
5. **两处高危道具**：银针（细、易穿模，建议实拍手部）、暗色血（平台敏感，备「浊气 + 黑帕」替代方案）。

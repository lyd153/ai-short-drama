## 二、逐人小传

### 邶峙珩 · 山主

- **年龄 / 身高**：21 岁 / 220cm。身形极高，站在族人中间像一根立着的枪。
- **外形**：墨蓝色暗纹交领锦袍，高束墨发；肤色偏白带病气；左手食指墨玉戒。
- **核心特征**：**右眼下有一颗泪痣**。这是他全身唯一「软」的地方——镜头只要推进到脸，这颗痣必须清楚可见；情绪崩坏的第一信号不是皱眉，而是那颗痣随着眼眶泛红变深。
- **身体**：每逢十五月圆子时寒毒发作，毒纹自腕脉而起，痛如骨缝结霜；需青萤灵草入药才压得住。
- **行为逻辑**：说话慢、笑先到眼；对下属是「闲散里带刀」，对女主是「玩味里带试探」。从不解释自己。
- **表演与运镜**：220cm 的演员（或生成形象）在画面里天然带压迫感。**情绪戏靠高度变化表达**：站着俯视她 → 被迫坐下/俯身 → 视线与她齐平，就是他动摇的刻度。坐下时他的膝盖会高于对方肩线，这个细节要刻意用。

### 林洛筱 · 医女

- **年龄 / 身高**：22 岁 / 176cm。在族中女子里算高挑，但站到他面前只到他胸口。
- **出身**：**由山间诸元素灵气凝聚而结成胚胎，发育成人**——无父无母，非血肉凡胎。
- **由出身体推出来的三件事**（写戏时要能用上）：
  1. **体温略低于常人**，握药时指尖发凉；他第一次碰到她的手会察觉。
  2. **对草木灵息敏感**：她识药不靠师承，是「听得见」草木在说什么——这解释她医术为何高于族中巫医。
  3. **伤口愈合快**，所以她不怕疼、下手也狠（给自己下针从不犹豫）。
- **外形**：浅蓝色对襟长裙（全片唯一高明度色块），左耳银铃，眉心淡青花钿，腰间旧皮药囊，指腹有药渍与细小伤口。
- **性格**：认死理、不讹人；凶不过三秒，说到正事立刻端正。
- **表演**：眼快手快、鼓腮、叉腰；慌时先攥裙摆，稳住立刻挺背。

### 萧漓 · 男二（本集未出场）

- **年龄 / 身高**：24 岁 / 218cm。
- **出身**：由灵泉滋养而生的白百合，修炼化形成人。
- **核心特征**：**左脸上方有白百合纹身图案**。设定为「活纹」：平时淡到几乎看不见，灵力波动或情绪起伏时花瓣变深；受伤时花瓣会「枯」——这是他的血量表。
- **性格（暂定）**：与男主的闲散相反——冷、直、讲究「干净」，说话不留余地。
- **与主线的关系**：待确认。三个候选方向：① 旧识兼医道对手（推荐，能立即给女主制造选择）；② 同为异类修行者、与男主有旧约；③ 青萤灵草产地的守护者。
- **出场规则**：本集只在台词或物件里留一个影子（可选：集市上有人提到「灵泉那边的人」），不露脸。

### 陆驰 · 贴身侍卫

## 三、身高带来的构图与美术硬约束

身高不是设定装饰，它直接改镜头和布景。**四人全部 ≥176cm，男主 220cm**，这组数字必须体现在画面里，否则观众会觉得「演员矮了一截」。

### 3.1 同框构图

| 组合 | 身高差 | 构图与运镜 |
| --- | --- | --- |
| 邶峙珩 × 林洛筱 | 44cm | 他俯视、她仰头；俯拍他 / 仰拍她。他俯身靠近时镜头随之前压，是她被压制的视觉语言 |
| 邶峙珩 × 陆驰 | 1cm | 几乎等高：用**肩宽、站姿、衣料**区分，不能靠身高 |
| 邶峙珩 × 萧漓 | 2cm | 等高对峙，靠**站位与视线高度**分出主次（谁先抬下巴谁输） |
| 林洛筱 × 萧漓 | 42cm | 同「他俯她仰」的构图，但用白百合纹身做视觉锤 |
| 全员群像 | — | **低机位 + 广角**，否则一群人像「巨人国」；正常平视机位会把所有人的头挤出画框 |

### 3.2 布景尺度（美术必须知道）

- 门楣净高 ≥ 2.4m，男主进门要**明显低头**——这是「他不属于普通屋子」的视觉证据。
- 榻长 ≥ 2.6m，他斜倚时脚不会悬空。
- 长街摊位台面高 1.1–1.2m，他俯身看货时腰要弯下去；女主站在摊后高度刚好。
- 群演平均身高按 170–175cm 选，靠身高差把主角「抬」出来。

### 3.3 AI 生成注意

- 提示词里写「身形极高 / 220cm 身高」，模型容易生成**比例失真**（腿过长、头过小）。补救：锚里加「匀称比例、八头身、肩宽与身高匹配」，并避免全身广角。
- 同框时用**景别切分**：他的脸与她的脸分开拍，靠剪辑建立身高差，比让模型画全身同框稳。

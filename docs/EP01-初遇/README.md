## 一句话故事

他每逢十五毒发，她要的是一株草的钱，他要的是能活过今夜的那株草——而把草叼走的，是他养的那只正在修炼化形的兔子。

## 核心设定

- **邶峙珩**（21 岁 / 220cm）：世外部落之主，右眼下有一颗泪痣。每逢十五月圆子时寒毒发作，毒纹自腕脉而起，痛如骨缝结霜，需青萤灵草入药才能压住。
- **林洛筱**（22 岁 / 176cm）：由山间诸元素灵气凝聚成胎而生的医女，无父无母、体温略凉、识药靠「听得见草木」。为大祭司采固本之药而来，认死理、不讹人。
- **陆驰**（24 岁 / 219cm）：邶峙珩自小随侍的贴身护卫，身手敏捷，忠、稳、怕主子。
- **萧漓**（24 岁 / 218cm）：男二，由灵泉滋养的白百合修炼化形，左脸上方有白百合纹身。**本集不出场**，第二集起登场。
- **小卡**：雄性灵兔，修行中，靠食灵草积灵力、图化形；通人言不能言，颈间铜铃为镇灵铃。
- **青萤灵草**：生于背光阴崖，五年一熟，夜里泛青荧；解寒毒的唯一药引，也是灵兽化形的上品。

完整设定（含身高差构图与布景尺度）见 [人物设定.md](人物设定.md)。

## 时间线

十四夜（立毒兆）→ 十五晨（赶集）→ 日落前必须得药 → 结尾字幕「今夜，十五」。

# 模板：错题本与周复盘

同一个坑一周踩两次，是流程问题，不是运气。这张表就是用来把「坑」变成「流程改动」的。

---

## 一、单条记录

```markdown
### 2026-11-04 ｜ EP01-U03-S02 ｜ F1 身份失败

- **现象**：男主特写里，右眼下泪痣消失，眉骨多了道细纹，像陆驰。
- **归类**：F1（身份）
- **验证**：同角色三镜并排对比 → 只有这一镜缺标记
- **根因**：提示词漏了「右眼下泪痣」，且未固定种子
- **修法**：补锚 + 固定种子 `seed=73021`
- **复测**：4 张里 3 张可用（75%）
- **流程改动**：把「标记锚」加入提示词模板，作为必填项
- **状态**：已闭环
```

## 四、周复盘四问（20 分钟）

1. **本周废片率是多少？**（数字，不凭感觉）
2. **出现最多的失败码是哪个？**（F1–F5 选一个）
3. **根因是提示词、资产、还是参数？**（只能选一个）
4. **下周只改哪一处？**（写下来，下周验证）

## 五、典型坑速记（可直接抄进错题本）

| 坑 | 归类 | 修法 |
| --- | --- | --- |
| 泪痣被磨皮抹掉 | F1 | 负面词加「过度磨皮」，生成后逐帧确认 |
| 两个角色像双胞胎 | F1 | 拉大剪影差异 + 同框编号 |
| 竖屏把人头顶裁了 | F2 | 构图上下各留 1/5 |
| 220cm 角色像巨人 | F2 | 加「比例自然、肩宽与身高匹配」 |
| 影子朝两个方向 | F3 | 只留一个主光，写清方位 |
| 手穿进袖子 | F3 | 手部特写改实拍 |
| 一条提示词写「先…再…」 | F4 | 拆镜 |
| 表情像戴面具 | F4 | 换生理细节 + 写「从 A 到 B」 |
| 口型对不上 | F4 | 先定配音再驱动 |
| 拼接处跳帧 | F5 | 上一段末帧作下一段首帧 |
| 拼接处色差 | F5 | 全片两套 LUT |
| 画面闪烁 | F5 | 统一帧率，重生成该段 |

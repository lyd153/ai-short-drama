# 失败码与诊断矩阵

## 为什么先分类

同一个「不对」，可能是四种完全不同的原因：

- 脸不对 → 可能是**身份**错（F1），也可能是**光照**错（F3）让人显得不像
- 动作糊 → 可能是**表演**设计错（F4），也可能是**运动幅度**过大（F5）

**归错类，改十次也没用。** 这张矩阵的作用是：看到一个症状，先定位到码，再动手。

---

## F1 身份失败

**表现**：串脸、换人、两个角色像双胞胎、配角抢了主角的脸、越拍越老/越拍越嫩

**判定**：把同一角色的三个不同镜头截图并排，看五官比例、发型轮廓、标记（痣/疤/铃）是否一致。

**根因与修法（按优先级）**

| 根因 | 验证 | 修法 |
| --- | --- | --- |
| 缺「不可复制标记」 | 提示词里搜「痣/疤/纹身/铃」，没有就是缺 | 补一处标记，逐镜必带 |
| 参考图没绑定或分工不清 | 看提示词有没有「图 X 管什么」 | 写「图 1 环境、图 2 人物，图 1 不提供人脸」 |
| 种子随机 | 看是否固定 seed | 同角色固定种子 |
| 角色特征互相污染 | 两个角色发型/服装太像 | 拉开剪影差异：身高、肩宽、发冠、披风 |
| 多人同框未编号 | 提示词里没有「谁在左、谁在右」 | 用双编号法（见 `04-资产与编号法.md`） |

**一句话**：一致性靠**标记 + 绑图 + 种子**三件套，缺一样都会串。

## F2 结构失败

**表现**：构图呆板、人物被挤、比例失真（头大/腿长/巨人感）、手穿衣服、物件穿模、竖屏上下被裁

**判定**：把画面缩小到手机尺寸看，一眼能不能认出主体；再看上下 1/6 与 1/5 有没有压到内容。

**根因与修法**

| 根因 | 验证 | 修法 |
| --- | --- | --- |
| 没写景别与焦段 | 提示词无「中近景 / 85mm」 | 补景别 + 焦段 + 机位 |
| 身高/比例未约束 | 极端身高角色（如 220cm） | 加「比例自然、肩宽与身高匹配」 |
| 双人横排挤压 | 竖屏里两个人并排 | 改前后错位，或拆成两个单人中近景 |
| 前景缺失 | 画面发空 | 加前景遮挡（枝条/帘子/人群） |
| 竖屏安全区 | 头部被裁 | 构图时上下各留 1/5–1/6 |

## F3 物理失败

**表现**：人悬浮、影子方向与光源不符、两个光源互相矛盾、物件穿过手、桌面上的东西没影子、水面不反光

**判定**：先找「光源在哪」，再看所有影子是否朝同一方向；再检查「接触点」（脚与地、手与物）是否可信。

**根因与修法**

| 根因 | 验证 | 修法 |
| --- | --- | --- |
| 多个光源但没写主次 | 提示词出现两个以上光描述 | 只留一个主光 + 一个补光，写清方位 |
| 没写接触与投影 | 提示词无「影子落在…」 | 加「影子落在青砖地上，朝右后方」 |
| 手部交互 | 手与物接触 | 改实拍或后期合成，AI 只出环境 |
| 场景描述互相冲突 | 写了「全黑」又写「月光」 | 删一半，只留一个基调 |

## F4 表演失败

**表现**：表情假（通用苦脸/标准笑）、动作糊成一团、眼神空、口型与台词对不上、情绪没有递进

**判定**：静音看 3 秒，能不能读出情绪；再打开声音，口型是否与音节对上。

**根因与修法**

| 根因 | 验证 | 修法 |
| --- | --- | --- |
| 一条提示词写了多个动作 | 出现「先…再…最后」 | 拆镜，一镜一动 |
| 写抽象情绪词 | 出现「悲伤/愤怒/开心」 | 换成生理细节：下眼睑松、喉结动、指节泛白 |
| 动作幅度过大 | 运动幅度 >7 | 降到 2–4 |
| 口型后配 | 先出画面后配音 | 静帧 → 定配音 → 口型驱动 |
| 表情没有起点 | 提示词只写结尾状态 | 写「从 A 到 B」：嘴角先松，再是眼睛 |

---

## F5 技术失败

**表现**：画面闪烁、镜头抖、分辨率不够、拼接处跳帧、边缘发虚、帧率不统一

**判定**：逐帧看首尾 3 帧；再看拼接点两侧的光与色是否连续。

**根因与修法**

| 根因 | 验证 | 修法 |
| --- | --- | --- |
| 分段生成未用首尾帧 | 拼接处跳 | 上一段末帧作下一段首帧 |
| 帧率混用 | 24fps 与 30fps 混剪 | 统一工程帧率再导 |
| 运动幅度过大 | 抖动 | 降幅度或改固定机位 |
| 生成分辨率低再放大 | 虚 | 原生 1080×1920 生成 |
| 调色逐镜做 | 拼接处色差 | 全片两套 LUT（夜/日） |

## 诊断矩阵（速查）

| 你看到的 | 先查 | 再查 | 最后 |
| --- | --- | --- | --- |
| 不像主角了 | 标记锚（F1） | 参考图分工（F1） | 种子（F1） |
| 两个角色像双胞胎 | 剪影差异（F1） | 同框编号（F1） | 换一个换发型/服饰 |
| 人看着矮了一截 | 机位高度（F2） | 焦段（F2） | 身高约束词（F2） |
| 手崩了 | 手是否特写（F3） | 是否多手（F3） | 改实拍 |
| 表情像戴面具 | 是否抽象情绪词（F4） | 是否多动作（F4） | 加「从 A 到 B」 |
| 说话对不上口型 | 是否先出画面（F4） | 音频是否后改（F4） | 重驱动 |
| 画面一闪一闪 | 帧率（F5） | 分段首尾帧（F5） | 重生成该段 |
| 拼接处跳 | 末帧/首帧是否同源（F5） | 调色是否统一（F5） | 补 2 帧过渡 |

---

## 归因纪律

1. **一张废片只归一个主因**。多因并存时，先修影响最大的那个，再复测。
2. **改完必须复测 4 张/4 段**，1 张不算验证。
3. **同类问题出现 3 次以上**，写进错题本并改流程，不要每次临场救。

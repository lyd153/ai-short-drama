# 资产与编号法：把「像」变成「锁死」

一致性问题 80% 出在资产阶段。这里给一套可执行的资产包与编号体系。

---

## 一、角色资产包（每角色必备）

| 资产 | 数量 | 要求 |
| --- | --- | --- |
| 三视图 | 3 | 正面 / 侧面 / 背面，同一光线条件 |
| 表情包 | 5 | 喜 / 怒 / 惊 / 羞 / 冷（同一角度） |
| 服化定稿 | 1 套 | 首饰、发饰、腰佩、鞋履全部标清 |
| 标记特写 | 1 | 痣 / 疤 / 纹身 / 缺角，单独一张大图 |
| 提示词锚 | 1 段 | 一行字，可直接复制进提示词 |
| 编号 | C1 / C2 / C3 | 全片唯一，不再改 |

**没有标记特写的角色，不要进生成阶段。** 标记是防止换脸的最后一道绳。

---

## 二、双编号法（防串脸）

两层编号：**角色号 + 图位号**。

```text
角色号：C1 男主 / C2 女主 / C3 男二 / C4 护卫
图位号：图 1 环境 / 图 2 女主 / 图 3 男主
```

### 提示词写法

```text
参考图分工：图 1 仅提供环境（陈设、光源方位、色调），不提供人脸；
图 2 为 C2 女主形象，图 3 为 C1 男主形象，五官发型服饰必须一致。

画面内位置：C1 在画面右侧，C2 在左侧，两人相距半臂。
```

### 三条规则

1. **角色号进每一镜**：`【C1】【C2】` 写在提示词最前。
2. **图位号写清「管什么、不管什么」**：尤其要写「图 1 不提供人脸」，否则环境图里的人会被搬过来。
3. **同框必有位置**：左/右/前后，写死。模型不会自己排。

### 为什么有效

把「一个人」拆成「编号 + 图 + 标记 + 位置」四个可核对的锚，任何一个镜头出错都能定位到具体哪一环。

---

## 三、镜号体系

```text
EP01-U03-S02
 │    │   └─ 本单元第 2 镜
 │    └───── 第 3 个 15 秒单元
 └────────── 第 1 集
```

- 单元号与分镜表、提示词、剪辑时间线三处一致。
- 重生成时只改后缀：`EP01-U03-S02-r3`（第 3 次重试），保留历史版本。
- 废片也保留编号，进错题本，方便回查。

---

## 四、参考图分工（五种常见组合）

| 组合 | 写法 | 陷阱 |
| --- | --- | --- |
| 环境 + 双人 | 图 1 环境；图 2 女主；图 3 男主 | 模型会拿图 1 的人当主角 |
| 单人 + 场景文字 | 图 1 人物；场景按文字 | 场景描述不够会显空 |
| 只给人物 | 图 1；场景描述完整 | 一致性最好，环境最弱 |
| 风格参考 | 图 1 风格（色调/质感），不管内容 | 内容会被一起搬 |
| 首尾帧 | 首帧 = 上一镜末帧 | 光变了就接不上 |

**通用保险句**：`参考图的构图与配色可以学习，但不要复制其中的人物与文字。`

## 五、版本命名

| 对象 | 命名 | 说明 |
| --- | --- | --- |
| 分镜文档 | `EP01_分镜脚本_V2_15秒单元.docx` | Vn 只在设定/结构变化时升 |
| 提示词 | `EP01-prompts.md` | 由脚本导出，不手改 |
| 数据 | `EP01.json` | 唯一数据源 |
| 生成片段 | `EP01-U03-S02-r3.mp4` | r 为重试次数 |
| 成片 | `EP01_v3_20261104_成片.mp4` | 日期 + 版本 |
| 资产 | `C1_邶峙珩_三视图.png` | 角色号 + 名 + 类型 |

# 模板：三档精准提示词

## 一、草稿档（1 行，试方向）

```text
主体 + 场景 + 一种风格
```

例：

```text
古装女子坐在窗边，冷月光，低饱和胶片质感
```

跑 3–5 次，确定方向。**不要在这一档调细节。**

---

## 二、标准档（4 行，日常生产）

```text
主体动作：__（谁 + 一个连续动作 + 动作链）
镜头：__（景别 + 焦段 + 机位 + 运动）
光色：__（色温 + 光源方位 + 影调）
风格：__（质感 + 参考 + 画质）
```

例：

```text
主体动作：年轻女子坐在窗边木凳上，右手捻着半片草叶，指尖缓慢搓动
镜头：中近景，85mm，平视微俯，镜头极缓推近（3 秒 10%）
光色：左侧窗冷月光 6500K 侧逆光，面部补光 40%，留一半阴影
风格：低饱和青黑调，皮肤有毛孔纹理，胶片颗粒，参考《一代宗师》浅景深
```

---

## 三、锁定档（6 行 + 参数，交片用）

```text
【意图】这一镜要观众记住：__
【参考】环境沿用图 1；人物形象参考图 2；图 1 不提供人脸
【主体动作】__
【镜头】__ 景别 / 焦段 / 机位 / 运动 / 运动幅度
【光色】__ 色温 / 光源方位 / 对比度 / 补光比
【风格】__ 质感 / 介质 / 参考 / 画质
【负面】__（按镜头类型拼接）
【参数】__ 画幅 / 帧率 / 时长 / 种子
```

---

## 四、10 条自检

1. 主体是不是第一句？（前置＝权重）
2. 有没有一个动作是「两个动作」？（有就拆）
3. 景别和焦段都写了吗？
4. 光写了色温、方位、影调三样吗？
5. 每个形容词都能在画面上找到证据吗？
6. 形容词超过三个了吗？（超了就删）
7. 锚点里的「不可复制标记」写了吗？
8. 负面词是按镜头类型选的，还是一次全塞？
9. 这一条改了几个变量？（≥2 就重跑对照）
10. 这条提示词打几分？（<8 不进批量）

## 六、常见改法示例

| 原始（模糊） | 改后（精准） |
| --- | --- |
| 女主很伤心地哭 | 她垂下眼，下眼睑先松，一滴泪停在睫毛上没落，喉结动了一下 |
| 男主霸气登场 | 低机位仰拍 15°，24mm，他自右三分线走入，下颌微抬，衣摆在身后展开 |
| 唯美的夜晚 | 冷月光 7500K 从右上方斜入，檐角投影落在青砖地上，空气中有细尘 |
| 高级的质感 | 低饱和、窄色域、柔和高光、无眩光、布料有纤维感 |
| 打斗很激烈 | 手持 35mm 跟拍，运动幅度 6，刀锋入画带出残影，尘土扬起 |

## 七、一页纸口诀

```text
主体前置，动作原子；
景别焦段，机位写死；
色温方位，三样齐全；
形容词仨，多一个删；
锚点标记，缺一换脸；
负面分类，不塞满筐；
一次一改，四张才判。
```

# 提示词精准化

**核心判断：提示词的精度 = 可验证性。** 一句描述如果画面上找不出「哪里能证明它成立」，它就是不精准的，写十遍也只是碰运气。

本技能把你脑子里的「差不多」变成模型能执行的「就这个」。

## 何时用

- 提示词写了很多遍，出图/出片总是不对
- 想让同一套提示词稳定复现（换模型也大致一致）
- 需要控制构图、光线、材质、镜头运动这些「参数级」的东西
- 要做 A/B 测试、批量生成、建立模板

## 三档精度

| 档 | 长度 | 用途 | 组成 |
| --- | --- | --- | --- |
| 草稿档 | 1 行 | 试风格、找方向 | 主体 + 场景 + 一种风格词 |
| 标准档 | 4 行 | 日常生产 | 主体动作 / 镜头 / 光色 / 风格 |
| 锁定档 | 6 行 + 参数 | 需要复现、要交片 | 标准档 + 参考图绑定 + 负面词 + 种子/参数 |

**规矩：不许从草稿档直接跳锁定档。** 先用草稿档试三五次方向，再用标准档，最后才上参数。

## 六步精准化

### 第 1 步：目标解码

问自己：**这张图/这一镜，观众要记住哪一件事？**
只能一件。记忆点越单一，提示词越短，命中率越高。

把「氛围好」「很高级」这类词划掉——它们不是目标，是愿望。

### 第 2 步：原子化

一句话只描述一个可观察的对象或动作。

- ❌ 「女主美丽动人地站在窗前，眼里含着泪光，窗外的月光洒在她身上」
- ✅ 主体：女主站在窗前；表情：眼眶湿，泪未落；光：窗边侧逆月冷光

一句话里塞三个对象，模型只会挑最眼熟的那个画。

### 第 3 步：参数化

把形容词换成可测量的词：

| 模糊 | 参数化 |
| --- | --- |
| 很美 | 五官比例匀称、皮肤有毛孔纹理 |
| 光很好 | 侧逆光 4300K，面部补光 40% |
| 镜头很帅 | 85mm，f/1.8，低机位仰拍 15° |
| 很高级 | 低饱和、窄色域、柔和高光、无眩光 |
| 电影感 | 24fps 快门 1/48、胶片颗粒、浅景深 |

### 第 4 步：锚定

固定身份与空间：

- **人物锚**：年龄 + 身高/体态 + 服饰 + 一处不可复制的标记（痣/疤/纹身）
- **空间锚**：房间朝向、陈设、光源位置（「窗在左后方」比「有窗」有用）
- **参考图绑定**：图 1 环境、图 2 人物，写清谁管什么

### 第 5 步：否定

负面词不是越多越好，是**越准越好**。按镜头类型拼接（见 `references/04-迭代法.md`）。
原则：只否定「这个镜头真的可能出现的错误」，不否定「别的东西」。

### 第 6 步：单变量迭代

一次只改一个变量，记录结果。改两个变量就永远不知道是谁起的作用。
详见 `references/04-迭代法.md`。

## 三条硬规则

1. **一个提示词只回答一个「什么」**：主体是什么。镜头、光、风格各占一行。
2. **每个词都要能被看见**：写「高贵」不如写「衣料是暗纹锦，袖口三指宽的金边」。
3. **形容词不超过三个**：超过三个就是形容词在替你思考。

## 失败归因（先归因再改词）

| 症状 | 归因 | 改法 |
| --- | --- | --- |
| 主体不对 | 主体描述被风格词淹没 | 主体提到最前，删一半风格词 |
| 长相变了 | 缺锚点 / 未绑参考图 | 加标记锚 + 固定种子 |
| 构图不对 | 没写机位与景别 | 补「低机位、中近景、85mm」 |
| 光不对 | 只写了「光好」 | 写色温 + 光源方位 + 影调 |
| 质感塑料 | 缺材质词 | 加「皮肤纹理可见、布料有纤维感」 |
| 动作糊 | 一条提示词多个动作 | 拆成多条 |
| 风格乱 | 混了两个流派 | 只留一个参考 + 一个质感词 |
| 负面词无效 | 否定太宽泛 | 换成具体缺陷名 |

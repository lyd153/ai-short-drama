# 精准化方法：从「像」到「就是」

## 一、可验证性：唯一判断标准

拿一句提示词问自己：**如果生成结果出来了，画面上哪一处能证明这句话被遵守了？**

- 「她很美」→ 找不到证据 → 不精准
- 「她的唇色偏淡、皮肤有毛孔纹理、左耳戴一枚小银铃」→ 三处都能验证 → 精准

**所有改写都服务于这一条。** 写不出验证点的词，删。

---

## 二、原子化：一句话一个对象

### 拆分规则

| 一句话里有 | 拆成 |
| --- | --- |
| 两个以上人物 | 分开写，或用「左为 A，右为 B」 |
| 一个动作 + 一个表情 | 动作一行、表情一行（模型会只画一个） |
| 环境 + 人物 | 环境先给，人物后给 |
| 三个以上形容词 | 只留一个最关键的 |

### 示例

```
❌ 一位清冷高贵的美人坐在窗边，神情忧郁，月光洒落，氛围感很强
✅ 主体：一名年轻女子坐在窗边木凳上
   表情：眼睑下垂，视线落在膝上，唇角平直
   光：窗外冷月光从左侧 45° 打进来，半张脸在暗处
   风格：低饱和、柔和过渡、胶片颗粒
```

## 三、顺序即权重

多数模型对**前置词**更敏感。固定顺序：

```text
1. 主体（谁 / 什么）
2. 动作与状态（在做什么）
3. 镜头（景别 / 焦段 / 机位 / 运动）
4. 光（色温 / 方位 / 影调）
5. 风格与质感（参考 / 介质 / 画质）
6. 负面词（最后）
```

**要强调的东西往前放**，不是加感叹号。

### 权重语法（按模型）

| 模型 | 写法 | 说明 |
| --- | --- | --- |
| Midjourney | `(词:1.3)` 或 `词::2` | 数值 0.5–2 |
| Stable Diffusion | `(词:1.3)`，`[词]` 降权 | 超过 1.5 容易崩 |
| 即梦 / 可灵 | 靠语序与重复，不用括号 | 重复关键词比括号稳 |
| Seedance | 靠语序 + 结构化段落 | 段落标题对它有效 |
| Veo | 自然语言长句 | 不要堆关键词 |

**通用做法**：不确定权重语法时，用「语序靠前 + 重复一次」代替括号。

## 五、参考图与种子

### 参考图分工

```text
环境沿用图 1（陈设、光源方位、色调）
人物形象参考图 2（五官、发型、服饰）
只参考人物图 1 的性格气质，不复制其服装
```

写清「图 X 管什么」，否则模型会把环境图的人脸也搬过来。

### 种子

- 同角色跨镜头：固定种子 + 固定锚点，一致性提升明显。
- 试风格阶段：随机种子，多跑几张找方向。
- 交片阶段：种子记进表格，方便重出。

## 六、长度的两个极端

| 太短 | 太长 |
| --- | --- |
| 无锚点，每次不一样 | 描述互相冲突，模型随机丢词 |
| 修法：补主体 + 镜头 + 光 | 修法：每类只留一个最关键的，其余删 |

**经验值**：单镜 60–160 字（中文）；超过 200 字大概率有冗余，砍掉最不重要的三分之一再试。

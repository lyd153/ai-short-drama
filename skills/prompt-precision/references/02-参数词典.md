# 参数词典：可直接抄的词

写提示词时最常见的卡点是「不知道专业词叫什么」。这里按类别给，抄就行。

---

## 一、景别

| 词 | 画面占幅 | 用途 |
| --- | --- | --- |
| 大远景 | 人物极小，环境占 90% | 定场、世界观 |
| 远景 | 人物占 1/4 | 场面、行动 |
| 全景 | 人物全身入画 | 走位、动作 |
| 中全景 | 膝以上 | 双人对话 |
| 中景 | 腰以上 | 关系、手势 |
| 中近景 | 胸以上 | 情绪（竖屏主力） |
| 近景 | 肩以上 | 微表情 |
| 特写 | 面部占满 | 情绪特写、封面 |
| 大特写 | 眼睛/唇/痣 | 极限情绪 |
| 微距 | 睫毛 / 指节 / 叶脉 | 质感、悬念 |

## 二、焦段（按 35mm 全画幅）

| 焦段 | 效果 | 典型用途 |
| --- | --- | --- |
| 14–16mm | 极大纵深，边缘畸变 | 航拍、狭小空间 |
| 24mm | 环境包容，轻微畸变 | 群像、室内 |
| 35mm | 接近人眼 | 纪实、跟拍 |
| 50mm | 标准，无畸变 | 对话、中近景 |
| 65–85mm | 略压缩，人像友好 | 微表情、心动 |
| 100mm macro | 极浅景深，细节锐利 | 眼睛、手、物件 |
| 135mm | 强压缩，背景虚化 | 人群中的孤独、远观 |

## 三、机位与角度

| 词 | 效果 |
| --- | --- |
| 平视 | 客观、平等 |
| 低机位仰拍 | 压迫、英雄感（角度 10–20° 最稳） |
| 高机位俯拍 | 弱小、被审视 |
| 顶拍（90°） | 命运感、仪式感 |
| 荷兰角（倾斜） | 失衡、危险 |
| 过肩 | 双人关系 |
| 主观视角（POV） | 代入 |
| 越轴反面 | 关系翻转（慎用） |

## 四、光位

| 词 | 效果 |
| --- | --- |
| 顺光 | 平、干净、无立体 |
| 侧光（45°） | 立体感强，五官分明 |
| 侧逆光 | 轮廓光，发丝发亮（心动/神圣） |
| 逆光 | 剪影、氛围、神秘 |
| 顶光 | 眼窝阴影、压迫 |
| 底光 | 恐怖、非常规 |
| 伦勃朗光 | 半明半暗，戏剧性 |
| 蝴蝶光 | 鼻下蝴蝶形阴影，美人光 |
| 分割光 | 明暗各半，人格分裂感 |

## 五、色温与影调

| 词 | 数值 | 感觉 |
| --- | --- | --- |
| 烛光 | 1800–3200K | 温暖、私密 |
| 晨光 | 4300K | 希望、清新 |
| 日光 | 5600K | 客观、真实 |
| 阴天 | 6500K | 冷静、压抑 |
| 月光 | 7500–9000K | 冷、神秘 |

**影调三件套**：对比度（高/低）、饱和度（高/低/窄色域）、高光（柔和/硬）。

## 六、质感与材质

```text
皮肤有毛孔与细纹、布料有纤维感与褶皱、金属有磨损与反光、木质有纹理与虫蛀、毛发根根分明、玻璃有轻微指纹与水汽、丝绸有垂坠与透光
```

**反向词**（避免塑料感）：哑光、粗糙、做旧、氧化、褪色。

## 七、画质与介质

| 词 | 效果 |
| --- | --- |
| 胶片颗粒 | 电影感、复古 |
| 35mm 胶片 | 暖调、柔和高光 |
| 数码锐利 | 干净、商业 |
| 轻微暗角 | 注意力集中 |
| 体积光 | 光柱、空气感 |
| 浅景深 | 主体突出 |
| 运动模糊 | 速度感 |
| 高动态范围 | 亮暗细节都在 |

## 八、镜头运动

| 中文 | 英文 | 效果 |
| --- | --- | --- |
| 推 | dolly in / push in | 靠近、压迫、心动 |
| 拉 | dolly out / pull back | 疏离、揭示环境 |
| 摇 | pan | 扫视、转向 |
| 移 | truck | 平行跟随 |
| 跟 | follow | 代入、紧张 |
| 升降 | crane up / down | 气势、命运 |
| 环绕 | orbit / arc | 对峙、展示 |
| 甩 | whip pan | 突发、转场 |
| 变焦推拉 | dolly zoom | 世界观崩塌 |
| 焦点转移 | rack focus | 注意力转移 |

**运动幅度**建议：文戏 2–4（0 静止 / 10 极限），超过 7 面部易崩。

## 九、构图

| 词 | 说明 |
| --- | --- |
| 三分法 | 主体压三分线 |
| 中心构图 | 对称、仪式感 |
| 对角线 | 动感 |
| 框架构图 | 门框/窗格，窥视感 |
| 引导线 | 视线被引向主体 |
| 前景遮挡 | 增加层次（枝条/帘子/人群） |
| 留白 | 呼吸感（竖屏尤其重要） |
| 负空间 | 孤独、压抑 |

## 十、人物状态

```text
体态：肩线打开/含胸、下巴微抬/收、重心偏移
神情：眼睑下垂、视线向下、唇角平直、眉心轻蹙、眼眶发红、鼻翼微张、喉结滚动
手部：指节泛白、指尖收紧、掌心朝上、拇指摩挲
```

**微表情词比情绪词有效 10 倍**：写「喉结动了一下」，别写「紧张」。

---

## 用法：不要把词典当清单

每镜只取 **3–5 个词**：一个景别、一个光位、一个质感、一个运镜。全抄一遍等于没说。

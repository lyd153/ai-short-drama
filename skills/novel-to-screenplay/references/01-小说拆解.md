# 小说拆解：从章节到 15 秒单元

拆解的目标不是「概括剧情」，是**找到能被拍出来的那几件事**。

---

## 一、三层拆解

同一段小说，至少拆三遍，每遍只记一件事。

### 第 1 层：事件层（发生了什么）

逐段问：**有人的位置/状态改变了吗？**
变了＝一个事件；没变＝一段描写，留作空镜或删。

输出：`场景 / 谁 / 做了什么 / 结果`

### 第 2 层：情绪层（观众该有什么感觉）

给每个场景标一个情绪曲线：`起 → 转 → 落`，三个词，不准是直线。
如果一场戏从头到尾都是「紧张」，它就等于没有紧张。

### 第 3 层：信息层（观众知道了什么、角色不知道什么）

- 观众知道 + 角色知道 = 常规叙事
- 观众知道 + 角色不知道 = **紧张**（信息差）
- 观众不知道 + 角色知道 = **悬念**
- 两边都不知道 = **惊吓**

短剧的钩子几乎全靠第二类：**观众比角色先知道**。

---

## 二、场景切分

**切场标准：地点变、时间变、关键人物进出，任一发生就切。**

小说里一段连续叙述可能横跨多个场景，必须拆：

> 他回房，天亮了，他去集市，遇见她。

→ 场景 1（夜·房）、场景 2（晨·集市）。中间用空镜 + 声音过渡，不用旁白。

每个场景必须回答：

1. 这一场**必须完成**的一件事（信息 / 关系 / 情绪）
2. 谁在场，谁不在场（不在场的人往往更重要）
3. 场景结束时，什么变了

答不出第 1 条，这场就该删。

## 三、15 秒单元映射

### 换算

- 单集 2–3 分钟 → 8–12 个单元
- 1 个场景 → 1–3 个单元
- 1 个单元 → 3–5 个镜头（每镜 3–5 秒）

### 分配原则

| 内容类型 | 单元数 | 理由 |
| --- | --- | --- |
| 开场 | 1–2 | 3 秒定生死，必须给足空间 |
| 信息交代 | 1 | 超过 1 个单元就是在念说明书 |
| 冲突 | 2–3 | 需要「起—升级—爆」 |
| 情绪高点 | 1–2 | 心动、反转、崩溃，给足镜头 |
| 结尾钩子 | 1 | 最后 15 秒决定追更率 |

### 单元卡

一个单元只填五格，写不满就是设计不足：

```text
功能：这一段必须完成什么（只写一件事）
情绪：起 → 转 → 落（三个词）
钩子：看完之后观众心里冒出什么问题
声音：BGM 情绪 + 关键音效
转场：用「物」转（烛火/帘子/钱袋/铃声），不用叠化
```

---

## 四、钩子与卡点

### 位置

| 时间位 | 要放什么 |
| --- | --- |
| 0–3s | 一个动作或一个异常画面，不要字幕、不要旁白 |
| 3–15s | 立住主角与他的「不对劲」 |
| 15–30s | 抛出问题（谁、为什么、会怎样） |
| 30–60s | 第一次升级 / 第一次反转 |
| 每 30s | 一个小钩子（新信息、新人物、新威胁） |
| 最后 15s | 信息差钩子：观众知道了角色不知道的事 |

### 卡点的三种写法

1. **话说到一半切断**：他说「其实我早就——」切黑。
2. **动作做到一半切断**：刀举起来，切黑。
3. **信息给一半切断**：她看见那株草，镜头推到她瞳孔，切黑。

卡点后**必须留 12 帧黑场**，黑场第一帧放声音（闷响/一句话），比画面更抓人。

---

## 五、删改原则

改编不是翻译，是**重排信息**。

| 可以改 | 不要改 |
| --- | --- |
| 信息释放顺序（先给结果还是先给原因） | 主线因果 |
| 场景数量与顺序 | 人物核心动机 |
| 谁先知道、谁后知道 | 最终结局 |
| 心理描写 → 动作/台词 | 人物关系网 |
| 叙述者视角 → 镜头视角 | 关键道具的功能 |

**判断标准**：改完之后，主线还在、人物没变、但「什么时候知道什么」变了——这就是成功的改编。

## 六、拆解产出模板

```markdown
## 场景 N｜地点｜时间｜内/外

- 在场：A、B（C 不在场但被提及）
- 事件：一句话
- 情绪：起 → 转 → 落
- 信息差：观众知道___，角色不知道___
- 必须完成：___
- 可用镜头素材：物件 1、声音 1、动作 1
- 拆成单元：U__、U__
```

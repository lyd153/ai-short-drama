# 负面提示词库

负面词的作用不是「防止难看」，是**防止模型替你做了不该由它做的决定**：换脸、加手指、加人、加字、加光。

原则：**一次写全，逐镜复用**。三包拼接：基础包 + 人物包 + 场景包。

---

## 一、基础包（每条必带）

```text
畸变、扭曲五官、多余杂物、杂乱背景、高饱和刺眼色彩、面部崩坏、手指畸形、动作抖动、夸张表情、浓妆、水印、文字、模糊、噪点过重、logo、字幕、低分辨率、重复图案、拼接缝
```

英文备选（部分模型吃英文）：

```text
deformed, distorted face, extra objects, cluttered background, oversaturated, broken face, mutated hands, jitter, exaggerated expression, heavy makeup, watermark, text, blurry, heavy noise, logo, subtitle, low resolution, repeating pattern, seam
```

## 二、人物包

```text
面部不对称、双眼变形、瞳孔异常、牙齿畸形、露齿、嘴型崩坏、多余手指、手指粘连、六指、指甲畸形、手臂融合、肢体断裂、脖子过长、头身比异常、身材比例失真、巨人感、塑料皮肤、过度磨皮、假人感、表情僵硬、双人脸部雷同、角色串脸
```

补充说明：

- **多人同框必加**「双人脸部雷同、角色串脸」——AI 会把两个角色画成一张脸。
- **全身镜头必加**「头身比异常、身材比例失真」——极端身高（如 220cm）尤其需要。
- **手部特写必加**「六指、手指粘连、指甲畸形」，并考虑实拍替身。

## 三、场景包

```text
现代服饰、现代建筑、电线、路灯、汽车、塑料制品、现代文字、招牌、绿幕边、穿模、悬浮物体、地面缺失、重复人群、远景黑块、光源矛盾、双太阳、雾过重
```

按场景可拆：

| 场景类型 | 追加负面 | 原因 |
| --- | --- | --- |
| 古装室内 | 现代家具、电灯、玻璃窗、塑料、瓷砖 | 模型爱加现代元素 |
| 市集 | 重复人群、真空街道、整齐划一的摊位 | 会失去烟火气 |
| 夜戏 | 死黑、纯黑背景、过曝月光 | 层次全丢 |
| 战斗 | 无重力、动作模糊、武器穿模、血浆过艳 | 打戏最易崩 |
| 灵兽/动物 | 拟人化、穿衣服、卡通化、雌性化 | 定位错就全片错 |
| 特效（灵气/法术） | 粒子爆炸、能量球、魔法阵、霓虹光 | 廉价感来源 |

## 四、画风包（按目标风格选一）

| 目标 | 负面 | 正向对应 |
| --- | --- | --- |
| 电影写实 | 卡通、日漫、3D 建模感、插画、赛璐璐 | 胶片颗粒、浅景深、真实皮肤纹理 |
| 古风写意 | 现代感、塑料光泽、过锐的 HDR | 水墨层次、柔和过渡、低饱和 |
| 甜宠轻喜 | 阴冷色调、恐怖氛围、硬光影 | 暖调、柔光、通透 |

## 五、平台差异

| 平台 | 负面词偏好 | 备注 |
| --- | --- | --- |
| 即梦 / 可灵 | 中文负面词效果好，越具体越好 | 人物一致性靠参考图，不靠负面词 |
| Seedance | 中英混写稳定；对「镜头运动」类负面词敏感 | 加「镜头剧烈抖动」可压住失控运镜 |
| Vidu | 中文为主 | 人物包要写全 |
| Veo | 英文负面更准 | 可把基础包翻成英文 |


**全身同框**

```text

```

**场景空镜**

```text

```

**灵兽镜头**

```text

```

**打斗镜头**

```text
无重力漂浮、武器穿模、动作糊成残影、血浆过艳、肢体扭曲、武器变形、背景人物静止不动
```

## 七、三条使用规则

1. **负面词也要「一镜一改」**：人物包只在有人脸时加，场景包只在有环境时加——全塞进去会让模型过度保守、画面发灰。
2. **负面词不能替代角色锚**：一致性靠参考图 + 锚点 + 固定种子，不靠「不要换脸」。
3. **崩坏先归因，再改词**：六指 → 手部特写改实拍；脸崩 → 补锚；糊 → 减动作、降运动幅度。

# 五类描写的可拍化改写

小说靠「叙述」推进，短剧靠「镜头」推进。同一句话，小说里成立，分镜里必须能被看见或听见。

**总规则：凡是镜头拍不到、话筒收不到的，都要翻译。** 心理 → 动作；解释 → 事件；形容 → 具体物件；旁白 → 台词或声音。

---

## 一、人物描写

### 规则

1. **五个锚点，全部可拍**：身高体态 / 衣料颜色与材质 / 发型 / 一件配饰 / 一处不可复制的标记（痣、疤、纹身、缺角）。
2. **身份用行为写，不用形容词写**：不写「他是上位者」，写「他说话时所有人都不自觉地闭了嘴」。
3. **反差只给一处**：全身禁欲的人，唯一软的地方是一颗痣；这处反差就是特写要拍的地方。

### 对照

| 小说写法 | 为什么不能拍 | 改写成镜头 |
| --- | --- | --- |
| 她美得不可方物 | 「美」不是画面 | 侧光下睫毛的影子落在颧骨上，他看了两秒才移开眼 |
| 他气质清冷疏离 | 抽象 | 别人说话时他看着窗外，回话只用两个字的鼻音 |
| 她是个倔强的姑娘 | 抽象 | 眼泪在眼眶里打转，她就是不让它掉下来，还抬手把它按回去 |
| 他很富有 | 不可见 | 别人用布包银子，他用绣云纹的锦袋，抓一把不数 |

### 记忆点设计

每个角色至少一件**能被观众复述**的东西：银铃、墨玉戒、缺角耳、白百合纹身。它在全片出现 ≥3 次，每次含义要变（第一次是装饰，第三次是命门）。

## 二、动作描写

### 规则

1. **动作链三段**：准备（重心/视线）→ 发力（肌肉/关节）→ 结果（物件/他人反应）。写全三段，模型才知道怎么动。
2. **一个动作 = 一条提示词**；两个动作写在一起就会糊。
3. **情绪藏在动作的「快慢」里**：犹豫＝慢半拍，决绝＝不减速，心虚＝多做一个小动作。
4. **给动作一个物理反馈**：袖口扫过、尘土扬起、水面涟漪——这是「真的在动」的证据。

### 对照

| 小说写法 | 改写成镜头 |
| --- | --- |
| 他愤怒地拍了桌子 | 手掌落桌，茶盏跳起半寸，茶水在盏沿晃出一圈，他没看它 |
| 她紧张地绞着手 | 指尖把袖口绞出三道褶，指甲掐进掌心，她自己没发觉 |
| 他轻功很好 | 足尖点瓦，瓦缝里一颗露珠被震得弹起，在月光里碎成星点 |
| 他扶她起来 | 他伸手，她没接，自己撑着桌沿站起来；他的手在空中停了半秒才收回 |

## 三、环境描写

### 规则

环境必须至少干一件事，否则删掉：

1. **交代时空**（这是哪、什么时候、什么季节）
2. **承载情绪**（同一间屋子，白天和夜里讲两件事）
3. **推动动作**（门、窗、雨、坡、台阶——让动作变成阻碍或助力）

### 写法

- **先给一个物件特写，再给全景**：观众靠物件认场景，不靠全景。
- **光是最便宜的情绪**：暖光＝安全，冷光＝危险，半明半暗＝暧昧。
- **声音补环境**：虫鸣、更漏、市集底噪、风穿过窗纸。画面只给一半，剩下给声音。

### 对照

| 小说写法 | 改写成镜头 |
| --- | --- |
| 这是一个贫穷的村庄 | 屋顶茅草稀稀拉拉，补丁用的是不同颜色的布；一只鸡从门槛下钻进去 |
| 夜很深了 | 更漏的水滴到最后一格；灯芯只剩一点红；远处一声犬吠，很快没了 |
| 气氛很压抑 | 屋里只有一扇窗，光照进来正好切在两人之间；谁越过那道光，谁就输了 |

## 四、生态描写（世界观与规则）

「生态」不是风景，是**这个世界怎么运转**。分三层：有什么（存在）、怎么运作（规则）、要付什么代价（代价）。

### 规则

1. **规则用「日常仪式」展示，不用旁白解释**：不写「这个世界的人要交灵石税」，写「集市口有个木箱，人人路过都往里丢一颗石头发亮的东西，没人看守」。
2. **代价让世界可信**：会飞的要耗寿，能治病的要折自己的元气。有代价的能力才像真的。
3. **三个信息里只明说一个**：说一个、演一个、藏一个。观众才会讨论。
4. **规则要能被镜头违反**：先立规则（第 1 集），再让人破一次（第 5 集），破规则就是高潮。

### 对照

| 小说写法 | 改写成镜头 |
| --- | --- |
| 灵草五年一熟，极难采摘 | 崖壁上只有一株发青光；采药人的手绳系着三枚旧铃——前三个都没回来 |
| 他每逢十五发作 | 墙上刻着十四道痕，最后一道是新刻的；窗外月亮已经很圆了 |
| 她是山灵所化 | 她走过的地方草会直起来；她自己没发现，他一直看着她的脚 |

## 五、语言描写

### 规则

1. **台词三问**：谁说的？为什么现在说？不说会怎样？答不出就删。
2. **写潜台词，不写心里话**：嘴上说「你走吧」，手上还攥着他的袖子。
3. **一句一个意思**，短、口语、能演。长句拆开，或用动作断句。
4. **信息差驱动对白**：让两个人知道的不是同一件事，台词才有张力。
5. **口语检验**：把台词念一遍，不像人说的话就重写。

### 对照

| 小说写法 | 改写成镜头 |
| --- | --- |
| 「我其实一直很在乎你。」 | 「你走的时候，我把灯留着。」（顿）「留了三年。」 |
| 「你必须相信我！」 | 「我要是骗你，」她把药碗放下，「这一碗我自己喝。」 |
| 「我知道了。」 | 「知道了。」（他把那半片叶子收进袖里，没再说话） |

### 台词功能表

每句台词至少承担一项，否则删：

| 功能 | 例子 |
| --- | --- |
| 给信息 | 「昨日你治好了我族的大祭司。」 |
| 立人物 | 「赔四十银币。多出来的，算这顽兔的赔罪。」 |
| 造冲突 | 「这草，你按十二银币一株卖了？」 |
| 埋伏笔 | 「明日就是十五了。」 |
| 给情绪出口 | 「……你怎认得我？」 |

## 五类合一的判断标准

一场戏写完，逐条问：

1. 有没有一句「解释性旁白」？→ 删或转成事件。
2. 有没有一个人物特征无法被镜头拍到？→ 换成能拍到的。
3. 有没有一个动作写成两个？→ 拆镜。
4. 环境有没有情绪功能？没有就压成一个空镜。
5. 世界观规则有没有代价？没有就补一个。
6. 台词有没有潜台词？没有就改一句。

# 分镜提示词：四行写完一个镜头

## 一、格式

```text
参考图绑定（一行）
主体动作 + 镜头（景别/焦段/机位/运动）+ 光色（色温/光源/影调）+ 风格（质感/参考/画质）
负面词（整段追加）
```

### 参考图绑定（有参考图时必写）

```text
生成视频：环境沿用图 1 场景；女主形象参考图 2，男主形象参考图 3；人物比例自然，站姿贴合环境。
```

规则：

- **环境图管陈设，人物图管长相**，不要互相混用。
- 多人同框时写清「谁参考哪张图」，否则模型会串脸。
- 没有参考图时，用角色锚代替（见第五节）。

### 四行正文

| 行 | 写什么 | 反面 |
| --- | --- | --- |
| 主体动作 | 谁、在做什么、一个连续动作、动作链三段（准备/发力/结果） | 「两人很甜蜜」——不是动作 |
| 镜头 | 景别 + 焦段 + 机位 + 运动（一个运动） | 「运镜很炫」——不是参数 |
| 光色 | 色温 + 光源方位 + 影调 | 「光线很好」——不是描述 |
| 风格 | 质感 + 参考作品 + 画质 | 「电影感」——太模糊 |

## 二、分段时间码

一个 15 秒单元按 4+4+5+2 或 4+4+4+3 切，每段写清起止：

```text
0–4s｜中近景，构图留白｜...
4–8s｜镜头匀速缓慢推近，转为特写｜...
8–13s｜镜头平滑切至男主面部特写｜...
13–15s｜回双人中近，收尾留白｜...
```

时间码的作用是**给剪辑一个契约**：生成时按段出，剪辑按秒对，不会拼不上。

## 三、景别与焦段对照

| 景别 | 竖屏用途 | 焦段 | 提示词写法 |
| --- | --- | --- | --- |
| 大远 | 定场、世界观 | 14–16mm | 航拍大远景，人物极小 |
| 全 | 场面、群像、动作 | 24–35mm | 全景，人物全身入画，环境占比 2/3 |
| 中全 | 双人对话、走位 | 35–50mm | 中全景，膝以上 |
| 中 | 对话、关系 | 50mm | 中景，腰以上 |
| 中近 | 情绪、竖屏主力 | 50–65mm | 中近景，胸以上，占屏 2/3 |
| 近 | 微表情 | 85mm | 近景，肩以上 |
| 特 | 情绪特写、封面 | 100mm | 特写，面部占满竖屏 |
| 大特 | 眼睛、泪痣、瞳孔 | 100mm 微距 | 大特写，眼睛占屏 1/4 |

竖屏规则：**特写占比 ≥40%**；一个单元的景别必须有变化，连续三镜同景别必平。

## 四、光色词表

| 需表达 | 提示词 |
| --- | --- |
| 安全 / 回忆 | 暖光 3200K，柔光板，低对比，暖橘调 |
| 危险 / 夜 | 冷月光 6500K，单一光源，高对比，青黑调 |
| 暧昧 | 侧逆光，面部补光 40%，留一半阴影 |
| 神圣 / 回忆杀 | 逆光，丁达尔光束，浮尘可见 |
| 病态 / 虚弱 | 冷白，低饱和，皮肤无血色 |
| 压迫 | 顶光，眼窝阴影，背景全黑 |
| 黎明 / 希望 | 4300K 逆光，青绿色雾气，暖金高光 |

必须写清三件事：**色温、光源方位、影调（对比度/饱和度）**。

## 五、角色锚

每人一行，逐镜追加：

```text
男主：21 岁东方古装男子，身形极高（约 220cm），墨蓝色暗纹交领锦袍，高束墨发，肤色偏白带病气，左手食指墨玉戒，右眼下有一颗泪痣，比例自然。
女主：22 岁苗疆少女，身高约 176cm、身量高挑，浅蓝色对襟长裙，左耳银质小铃，眉心淡青花钿，腰间旧皮药囊，指腹有药渍。
```

锚点选取原则：**一处不可复制的标记** > 服装 > 体态。标记（痣/疤/纹身/缺角）是防止 AI 换脸的最后一根绳。

## 六、参数

| 项 | 建议 |
| --- | --- |
| 单段时长 | 5s 为主，复杂动作 8s |
| 首尾帧法 | 上一段末帧作下一段首帧，保证姿态、光线、视线连续 |
| 运动幅度 | 0–10 档，文戏 2–4；超过 7 容易面部崩坏 |
| 画幅 | 9:16，1080×1920；安全区上 1/6、下 1/5 |
| 帧率 | 24fps；升格段单独出 60/90/120fps 再放慢 |
| 生成顺序 | 先定妆参考帧 → 再批量出镜 → 只重生成出错的那 5–8 秒 |

## 七、常见失败与改法

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 换了个人 | 锚点不全 / 未绑参考图 | 补锚 + 固定种子 + 绑定参考图 |
| 动作糊 | 一条提示词多个动作 | 拆镜，一镜一动 |
| 脸崩 | 运动幅度过大 / 景别太近还带快速运动 | 降幅度，或改「固定机位 + 微动」 |
| 画面发灰 | 负面词塞太多 | 按场景删掉无关负面包 |
| 比例怪 | 未写身高与比例约束 | 加「比例自然、肩宽与身高匹配」 |
| 光线平 | 只写「光好」 | 写色温+方位+影调 |
| 缺电影感 | 无景别变化、无前景遮挡 | 加前景（枝条/帘子/人群）与景别切换 |

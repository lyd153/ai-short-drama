## 二、四行单镜模板（批量生成时用）

```text
【镜号】U__-S__ ｜ __s ｜ __
主体动作：__（谁 + 一个连续动作 + 动作链三段）
镜头：__（景别 + 焦段 + 机位 + 运动）
光色：__（色温 + 光源方位 + 影调）
风格：__（质感 + 参考 + 画质）
负面：__
```

## 三、填好的示例（甜宠向）

```text
【镜号】EXTRA-01-S02 ｜ 4s ｜ 特 ｜ 100mm
主体动作：女主面部特写，缓缓嘟起唇，幅度轻柔不夸张，眼尾自然垂落，瞳孔漫着柔和的光，笑意藏在眼底，没有大笑，面部肌肉微动。
镜头：100mm 微距，f/2.0，匀速缓慢推近（4 秒走完屏宽 8%），焦点从睫毛过渡到瞳孔，浅景深。
光色：侧逆光，暖调 4300K，糖壳在画面边角虚化成金色光斑，面部补光 40%，留一半阴影。
风格：电影级写实，胶片颗粒，参考《一代宗师》浅景深；禁止日漫感、3D 建模感。
负面：畸变、扭曲五官、面部崩坏、手指畸形、夸张表情、浓妆、露齿、塑料皮肤、过度磨皮、日漫感、水印、文字、模糊。
```

## 四、参考图绑定写法

| 情况 | 写法 |
| --- | --- |
| 有环境图 | 环境沿用图 1 场景，陈设与光位保持一致 |
| 有男女主图 | 女主形象参考图 2，男主形象参考图 3，五官、发型、服饰一致 |
| 只有人物图 | 人物形象参考图 X，场景用文字描述：__ |
| 两角色同框 | 左为女主（参考图 2），右为男主（参考图 3），不要互换 |
| 无参考图 | 用完整角色锚代替，并固定随机种子 |

## 五、粘贴版（一批镜头连续投喂）

```text
[U01-S01] 5s | 大远 | 14mm
主体动作：...
镜头：...
光色：...
风格：...

[U01-S02] 4s | 特 | 100mm
主体动作：...
```

每次只改「主体动作」与「镜头」两行，光色与风格尽量保持不变——这是 48 个镜头「像同一部片」的唯一办法。

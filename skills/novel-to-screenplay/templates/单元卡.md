# 模板：单元卡与人物锚

## 一、15 秒单元卡

复制下面这段，一个单元一份。

```markdown
## U__ ｜ 00:00–00:15 ｜ 标题

| 项 | 内容 |
| --- | --- |
| 功能 | 这一段必须完成的一件事（只写一件） |
| 情绪曲线 | 起 → 转 → 落 |
| 观众钩子 | 看完观众心里冒出的那个问题 |
| 声音 | BGM 情绪 + 关键音效（声音先行） |
| 转场 | 用「物」转：烛火 / 帘子 / 钱袋 / 铃声 |
| 镜数 | 3–5 |
| 时长 | 15s（如 4+4+5+2） |
```

### 填写示例

| 项 | 内容 |
| --- | --- |
| 功能 | 用一个动作（揉头顶 + 蹭手心）说完「高冷男主 × 软乖女主」的关系 |
| 情绪曲线 | 松弛甜 → 心动软 → 克制宠 |
| 观众钩子 | 他那一抹几乎看不见的笑，到底算不算喜欢 |
| 声音 | 竹笛轻快 → 只留单音 + 呼吸 → 风铃一声收尾 |
| 转场 | 糖葫芦虚化在两人之间 |
| 镜数 | 4 |
| 时长 | 15s（4+4+5+2） |

## 二、人物锚卡

```markdown
### 角色名（身份）

- 年龄 / 身高：__
- 身份：__
- 五个可拍锚点：
  1. 身高体态：__
  2. 衣料颜色与材质：__
  3. 发型：__
  4. 配饰：__
  5. 不可复制的标记：__（痣 / 疤 / 纹身 / 缺角）
- 表演关键词：__（说话速度、动作幅度、笑的方式）
- 声线：__
- 提示词锚（复制用）：__
```

### 示例

```text
男主：21 岁东方古装男子，身形极高（约 220cm），墨蓝色暗纹交领锦袍，高束墨发，肤色偏白带病气，左手食指墨玉戒，右眼下有一颗泪痣，比例自然，慵懒矜贵。
```

## 三、场景卡

```markdown
## 场景 N｜地点｜时间｜内/外

- 在场：__
- 事件：一句话
- 情绪：起 → 转 → 落
- 信息差：观众知道___，角色不知道___
- 环境功能：交代时空 / 承载情绪 / 推动动作（三选一，至少一个）
- 可用物件：__
- 可用声音：__
- 拆成单元：U__、U__
```

## 四、风险镜卡

对每一处高风险镜头单独记一行：

```markdown
| 镜号 | 风险类型 | 具体风险 | 替代方案 |
| --- | --- | --- | --- |
| U06-S02 | 手部特写 | 六指/穿模 | 实拍手部，AI 只出环境 |
| U12-S04 | 快速拉远 | 面部崩坏 | 拆两段：拉远 + 定格 |
```

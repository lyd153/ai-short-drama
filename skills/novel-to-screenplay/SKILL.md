# 小说转剧本 · 分镜与提示词技能

一套从「文字」到「可生成的镜头」的完整流程：拆小说 → 立人物 → 切场景 → 排 15 秒单元 → 写分镜 → 出提示词 → 配负面词 → 质检。

铁律只有一条：**只写镜头能拍到的。** 看不见的心理、解释、旁白，全部翻译成动作、表情、台词、声音、光线。

## 何时用

- 把小说 / 网文 / 剧本改成短剧分镜
- 拆场景、排节奏、找钩子与卡点
- 人物、动作、环境、生态、语言描写「可拍化」改写
- 生成逐镜 AI 提示词（即梦 / 可灵 / Seedance / Vidu / Veo）
- 选运镜、定景别、写负面词、做分镜质检

## 输入契约

至少需要三样，缺一样先问用户要：

1. **原文**（小说章节、剧本片段，或一句故事梗概）
2. **人物锚**（外形 5 个可被镜头看见的特征；没有就用 `templates/单元卡.md` 里的字段反推）
3. **画幅与时长**（默认 9:16 竖屏、单集 2–3 分钟、15 秒单元）

可选：参考图（环境图 / 女主图 / 男主图）、平台（红果 / 抖音 / 快手）、生成模型。

## 输出契约

| 产出 | 形态 |
| --- | --- |
| 拆解表 | 场景 × 事件 × 情绪 × 信息差 |
| 人物锚 | 每人一行，可直接追加进提示词 |
| 15 秒单元卡 | 功能 / 情绪曲线 / 钩子 / 声音 / 转场 |
| 分镜表 | 镜号 / 时长 / 景别焦段 / 运镜 / 画面表演 / 台词声音 |
| 逐镜提示词 | 四行（主体动作 / 镜头 / 光色 / 风格）+ 参考图绑定 + 负面词 |
| 质检报告 | 12 条自检 + 失分项与改法 |

## 九步流程

### 第 1 步：拆小说（见 `references/01-小说拆解.md`）

删三样：心理描写、作者解释、重复场景。留两样：**动作**、**信息差**。
输出场景表：地点 / 时间 / 在场人 / 这一场必须完成的一件事。

### 第 2 步：立人物锚（见 `references/02-五类描写可拍化.md`）

每人 5 个特征，必须是**能看见的**：身高、体态、衣料、饰品、一处不可复制的标记（痣 / 疤 / 纹身 / 缺角）。
禁止「绝美」「气质出尘」这类词——它不是画面。

### 第 3 步：切 15 秒单元

一集 = 12 个单元 = 180 秒。一个单元只干一件事。
单元卡五格：功能 / 情绪曲线 / 钩子 / 声音 / 转场（模板见 `templates/单元卡.md`）。

### 第 4 步：写分镜表

每单元 3–5 镜，每镜 3–5 秒。镜号要能直接对到生成批次。
分镜表只写：景别焦段、运镜、画面与表演（含微表情）、台词与情绪、时长、声音。

### 第 5 步：写四行提示词（见 `references/03-分镜提示词.md`）

```text
主体动作 + 镜头（景别/焦段/机位/运动）+ 光色（色温/光源/影调）+ 风格（质感/参考/画质）
```

开头一行绑定参考图：`环境沿用图 1；女主参考图 2；男主参考图 3；人物比例自然。`

### 第 6 步：选运镜（见 `references/04-大师运镜.md`）

先问「这一镜要观众感觉到什么」，再选技法；不要反过来先挑炫技。
文戏默认固定 + 极缓推；情绪反转才切特写；一场戏最多用一次「炫」的镜头。

### 第 7 步：配负面词（见 `references/05-负面提示词库.md`）

基础包 + 人物包 + 场景包，三包拼接。负面词一次写全，不要逐镜重写。

### 第 8 步：自检（见 `references/06-质检清单.md`）

12 条硬检查：节奏、钩子、微表情、一致性、时长、负面词覆盖。不过不改稿。

### 第 9 步：导出

- 分镜与提示词写进仓库对应目录（`docs/EP0X-剧集名/`、`prompts/`、`data/`）
- 提示词同时给「人读版」与「粘贴版」（每镜一段，可直接批处理）
- 长文档用 Word；数据用 JSON；两者必须同源

## 三条硬规则

1. **一个动作一条提示词**。写「先……再……最后」的，拆镜。
2. **不写抽象情绪，写生理细节**：不写「悲伤」，写「下眼睑先松，喉结动了一下」。
3. **每条提示词都带角色锚**：缺一个特征，模型就换一个人。

## 失败处理

| 症状 | 先改哪里 |
| --- | --- |
| 生成出来「像另一个人」 | 角色锚不全，或参考图没绑定；补锚 + 固定种子 |
| 动作糊成一团 | 一条提示词写了多个动作，拆镜 |
| 画面「AI 感」 | 光色行太笼统；写清色温、光源方位、影调 |
| 没有电影感 | 缺景别变化；连续三镜同景别就会平 |
| 手部崩坏 | 手部特写改实拍或后期，AI 只负责环境与光 |
| 节奏拖 | 单元功能重复；一个单元只留一件事 |
